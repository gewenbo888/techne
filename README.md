# Techne · 技艺

A systems-level exploration of technology as the extension of human capability across energy, information, coordination, and intelligence — and the layered evolution of civilization that follows. Bilingual (EN / 中文), light/dark, technical-philosophical aesthetic with Marcellus SC + Outfit + Fira Code on cosmos-default. Eleven chapters: hero capability schema (four extensions plus center); definition module with formula and four hard-cases (fire, writing, money, AI); five-axis capability extension table; energy ladder from fire to compute (8 steps with kcal/p/d); 6-step information revolution grid; 6-rung coordination scale ladder; 4-domain consciousness module (writing, clock, smartphone, AI); 6-wave technology timeline (Stone → AI); civilization simulator picking among 5 technologies projected across 5 dimensions; 4-frontier future module (AI, biotech, BCI, decentralized coordination); 6 risk/trade-off entries; AI Philosopher Q&A with 5 multi-thread canned responses (invisibility of mature tech, AI's recursive nature, determinism question, civilization rollback feasibility, what "remaining human" means).

## Stack

Plain HTML, CSS, vanilla JavaScript. No build step. Bilingual via `[data-lang]` + CSS attribute selectors. Light/dark via `[data-theme]`. Marcellus SC display (small caps inscriptional), Outfit body (geometric sans), Fira Code mono. All diagrams inline SVG. JS uses template literals throughout — verified with `node --check`.
